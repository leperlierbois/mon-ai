🔑 Mon IA et ma clé

Clé gratuite : va sur aistudio.google.com/apikey, connecte-toi avec ton compte Google, clique sur « Create API key », puis copie-la ici. Aucune carte bancaire n'est demandée.

La liste des modèles se charge quand ta clé est enregistrée. Les modèles « Flash-Lite » ont le plus de demandes gratuites par jour.

Crée une clé sur console.anthropic.com. C'est payant à l'usage : mets une limite de dépense sur ta clé.

Tes clés restent uniquement dans ce navigateur, jamais sur GitHub. Garde ton appareil verrouillé.
