# Mon IA

Mon assistant IA personnel, hébergé gratuitement sur GitHub Pages.

- Chat avec Google Gemini (gratuit, par défaut) ou Claude d'Anthropic (payant), recherche web et lecture des liens collés.
- Page **Réglages** : choix de l'IA et clé API, règles et limites personnelles (envoyées avec chaque demande), infos « À propos de moi », choix du modèle.
- Tout est stocké uniquement dans le navigateur (localStorage). La clé API n'est jamais dans ce dépôt.
